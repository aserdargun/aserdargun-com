### 1.3 Deploy Workflow — `azure/static-web-apps/deploy@v1`

Tüm 16 projede `deploy-swa-<code>-aserdargun-com.yml` adıyla tek dosya. Ortak adımlar:

```yaml
on: [main branch push + workflow_dispatch]
runs-on: ubuntu-latest
defaults: { run: { working-directory: ./<code>-aserdargun-com } }
steps:
  - uses: actions/checkout@v4
  - uses: actions/setup-node@v4  # node 22 (cld=24, gpu=22.x, usl=22.13.1, swi=22.23.1)
  - run: npm ci
  - run: npm run check  # veya validate, validate:codex
  - run: npm run build
  - run: test -f <out|dist>/staticwebapp.config.json   # ya da -s
  - uses: azure/static-web-apps/deploy@v1
    with:
      action: upload
      app_location: out  # next; dist # vite
      output_location: ""
      azure_static_web_apps_api_token: ${{ secrets.AZURE_STATIC_WEB_APPS_API_TOKEN_<CODE> }}
```

**Sapanlar (sıra dışı):**
- **aia:** ek "Verify static export" step'i var (write release manifest)
- **bee:** ek "Verify deployed commit and browser workflows" step'i (post-deploy guard)
- **ant:** ek "Verify production release and assets" + artifact upload `ant-deployment-browser-failures`
- **itl:** "Assert prebuilt static artifact" step'i (routes + CSP assert)
- **cld:** Playwright cache + browser test step
- **lcl, gpu:** Artifact pre-verified localde; workflow sadece upload

**Template notu:** 16/16 `azure/static-web-apps/deploy@v1` kullanıyor, hiçbiri `@v2`'ye geçmemiş. Sürüm drift'i yok; ama "azure-swa@v1 deprecated olabilir" riski açık.
